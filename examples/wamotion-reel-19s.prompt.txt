Make a 15–20-second brand reel, 1920×1080, for Wamotion. Not a tutorial and no feature list: a reel that makes a Remotion or agent developer want to install it, with the confidence of a studio title sequence. Facts: Wamotion is material for an agent that writes Remotion itself — an offline sound and music bank with measured timing, a tempo measurer, optional ears that score the mix, a CC0 3D character kit for @remotion/three, and one fresh-eyes review round. Open source, MIT. One-line install: `npx skills add hi-thanhn/wamotion`. If you want more, the repo's README is at /Users/thanhn/projects/wamotion-public/README.md. Sound must be the best part of this film. Use real 3D where it earns its place. All on-screen text in English. Build it with Remotion in this folder and render it to out/wamotion-reel.mp4.
