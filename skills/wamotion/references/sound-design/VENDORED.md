# Vendored: sound-design

Wamotion's own skill (plan/61, #253) wrapping material from earshot — https://github.com/Leonxlnx/earshot (MIT),
commit 591fa3e028032e6dce56620a20e932e35667e8d8 (2026-10-22). Installed into every project as
`.claude/skills/sound-design/` (without this file), the same way as motion-prompt: information to
look up, not a step, lint or review question (`.claude/rules/dont-over-constrain.md` rule 8; blind A/B pending — plan/61
§61.6).

Files:
- `SKILL.md` — ours. What the references measurably do, how to write `<Audio>` into `worlds/film.tsx`, where sounds
  come from in order (real recordings → designed UI sounds → made on the user's key), how to hear, three different
  examples. No MUST/NEVER in caps (`packs.test.ts`).
- `launch-video-sound.md` — earshot `docs/launch-video-sound.md` verbatim plus an "In Wamotion" note and two
  sentences replaced (`skills/real-sound/` → Wamotion commands).
- `kit.md` — generated once from `earshot/forge/kits/launch.json` (script in the plan/61 session; regenerate by hand
  if the kit changes).
- `bank.md` — GENERATED by `pnpm --filter @workspace/video-styles gen` from `apps/sidecar/assets/sound/manifest.json`:
  every bank sound (CC0 + earshot `es-…`) with kind, roles, length, description and `peakLagSec`.
- `CREDITS_FIT.md`, `LICENSE.md` (MIT), `NOTICE.md`.

Re-rendering the earshot sounds: `<venv>/bin/python apps/sidecar/scripts/sound-bank/earshot-render.py <dir>` then
`pnpm --filter sidecar sound-bank --earshot <dir>` (plan/61 §B).
